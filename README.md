# BetPanel · 包廂熱場投注系統

現場即時下注平台，專為酒店包廂、KTV、酒吧等娛樂場所設計。

## 功能特色

- **房間制**：幹部開房產生 QR Code，客人掃碼免註冊即可加入下注
- **即時浮動賠率**：貝氏動態調價引擎，資金湧入自動調整賠率
- **莊家抽水**：可自訂 0%~15% 抽水率，內建於賠率中自動計算
- **多種盤口模板**：1v1 對決、多選一、自訂盤口
- **一鍵結算帳單**：遊戲結束後自動產出包廂結算帳單
- **即時同步**：Firebase 即時資料庫，所有人看到同一份資料

## 使用方式

### 幹部（莊家）
1. 開啟 `banker.html`
2. 輸入名字、設定抽水率，點擊「建立包廂」
3. 將 QR Code 或房間代碼分享給客人
4. 口頭宣布後在系統「開盤」→「鎖盤」→「選擇贏家結算」

### 客人（玩家）
1. 掃描 QR Code 或開啟 `index.html` 輸入房間代碼
2. 輸入暱稱，瀏覽開放中的盤口
3. 選擇選項、輸入金額、下注

## 技術架構

- **前端**：純 HTML / CSS / JavaScript（無框架依賴）
- **資料庫**：Firebase Realtime Database
- **設計**：Mobile-first 響應式設計，暗色霓虹主題

## 檔案結構

```
app.js        核心引擎（賠率計算、驗證、結算，不含 DOM）
index.html    玩家頁面（掃碼加入、下注、查看結果）
banker.html   幹部後台（開房、開盤、鎖盤、結算、報表）
style.css     共用樣式（暗色霓虹主題）
```
